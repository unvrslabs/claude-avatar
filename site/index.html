Claude Avatar

A tiny desktop pet for Claude Code. Clawd thinks, types, runs commands, celebrates your green tests and falls asleep when you stop. One avatar per session, synced through Claude Code hooks.

curl -fsSL https://avatar.unvrslabs.dev/install.sh | bash
Live states

Thinking, typing, running, success with confetti, errors, waiting for you, sleeping.

One pet per session

Three terminals, three Clawds, each tagged with its project name. Stacked, draggable.

Status line included

Minimal state plus model, folder and git branch at the bottom of every Claude Code session.

Light and local

Zero-dependency Node server on loopback only. Native window. Clean uninstall.

Open with avatar in your terminal or /avatar inside Claude Code. macOS, Node.js, jq required. Source on GitHub.
